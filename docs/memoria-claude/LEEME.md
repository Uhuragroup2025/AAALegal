# Memoria de Claude para este proyecto

Copia de la memoria persistente de Claude Code (preferencias de Oscar y criterios de trabajo) para que viaje con el repositorio. En el equipo original vive fuera del proyecto, en `~/.claude/projects/<ruta-del-proyecto>/memory/`, y no se sincroniza sola.

**En otro equipo:** después de abrir el proyecto una vez en Claude, pedirle: "importa la memoria de `docs/memoria-claude/`". También se pueden copiar estos archivos a mano a la carpeta `memory/` del proyecto dentro de `~/.claude/projects/`.

Si la memoria cambia en un equipo, volver a copiarla aquí y hacer commit.
